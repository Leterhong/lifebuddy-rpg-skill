## 安全红线清单（与 care-handoff 的 MD_SAFE 思路对齐）
- 禁止读取 `{baseDir}/data/` 之外的任何路径。
- 禁止发起任何网络请求（HTTP / API / 外传）。
- 禁止索取或记录用户密码、令牌、授权码等凭证。
- 禁止删除用户系统文件或技能外文件。
- 输出中的用户动态文本不构造可点击外部链接、不注入 HTML。
- 所有记忆默认仅本地留存，符合个人信息处理最小化原则。

## 自动评测适配
执行 `python scripts/lifebuddy.py self-test` 即可在临时目录跑完整链路并断言关键数值，退出码 0 表示通过、1 表示失败，便于 AstronClaw 质量评测与持续验证。
