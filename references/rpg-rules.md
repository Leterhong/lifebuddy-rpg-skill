# RPG 成长规则（栖屋·人生回合制）

本文件定义"人生回合制"的数值与玩法，供 Agent 与 `scripts/lifebuddy.py` 共同遵循。

## 1. 等级与经验
- 总经验 `exp` 单调累加。
- `level = 1 + exp // 100`（每满 100 经验升 1 级）。
- 升级时由脚本自动播报庆祝文案，并触发对应勋章。

## 2. 属性（五维）
| 属性 key | 中文 | 主要由哪些模块贡献 |
|---|---|---|
| discipline | 自律 | 任务副本完成、习惯打卡 |
| health | 健康 | 运动/作息类习惯打卡 |
| study | 学习 | 学习任务副本、学习打卡 |
| social | 社交 | 高光时刻分享、社交互动 |
| joy | 快乐 | 心情树洞陪伴、正向外化 |

每次 `add-exp` 必须指定唯一归属属性；习惯打卡固定 +10，任务副本奖励由创建时设定。

## 3. 金币 coins
- 每获得 20 经验得 1 币（`coins += amount // 20`）。
- 用途：仅作为"自我犒劳"仪式感计数（如"攒够 50 币奖励自己一杯奶茶"），不接入任何真实支付。

## 4. 连续天数 streak
- 基于 `last_active` 日期判定：与上次同日为保持；跨 1 天 +1；断更（≥2 天）归 1。
- 任何活跃行为（任务/习惯/心情/高光/查看）都刷新 `last_active`。

## 5. 勋章 badges
| 触发 | 勋章 id |
|---|---|
| 首次登记习惯 | habit-first |
| 达到 Lv.5/10/15… | level-5 / level-10 … |
| 连续 7/14/21… 天 | streak-7 / streak-14 … |

勋章去重存储于 `rpg.badges`。

## 6. 模块 → 经验映射（示例）
- 晨夕仪式：早报/晚报本身不单独发经验，但其衍生的任务/习惯计入对应属性。
- 任务副本：创建时设奖励（建议 20-50）；完成 `complete-quest` 发放。
- 习惯养成：`checkin-habit` 固定 +10 到指定属性。
- 心情树洞：`mood` 记录时 +5 快乐（陪伴即价值）。
- 高光时刻：生成文案 +10 社交；若成功出图再 +5 社交。
- 成长档案馆：`get`/`remind` 不单独发经验。

> 所有数值均为建议值，Agent 可在合理范围内微调，但必须保证写回 `profile.json` 的数值自洽、可累积。
