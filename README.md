# 栖屋 · 人生回合制生活搭子（lifebuddy-rpg）

> 一个会陪你升级的生活助理 Skill —— 把平淡的每一天，变成一场好玩、有陪伴、能成长的人生回合制游戏。

## 一句话介绍
将日常任务、习惯、心情与高光时刻**游戏化**为「人生回合」，融合**实用性 × 娱乐性 × 情感化**，并用本地 JSON 持久化你的画像与成长曲线。你不是在用一个工具，而是多了一个记得住你、会鼓励你的生活搭子。

## 六大模块
| 模块 | 解决什么 | 亮点 |
|---|---|---|
| 晨夕仪式 | 每天开工/收尾没节奏 | 早报 + 晚报，温柔有陪伴 |
| 任务副本 | 大目标无从下手 | 拆副本、发经验、可追踪 |
| 习惯养成 | 坚持总是三天打鱼 | 连续天数 + 属性成长 + 勋章 |
| 心情树洞 | 情绪没处安放 | 共情陪伴 + 本地日记 |
| 高光时刻 | 想发圈却词穷 | 多风格文案 + 氛围配图（可降级） |
| 成长档案馆 | 看不见自己的进步 | 等级/属性/勋章/重要日子提醒 + **可视化成长图** |

## RPG 成长模型
- **等级**：每 100 经验升 1 级
- **五维属性**：自律 / 健康 / 学习 / 社交 / 快乐
- **金币**：每 20 经验得 1 币（仪式感计数，不接入真实支付）
- **连续天数**：跨天活跃累计，断更归 1
- **勋章**：首习惯、等级里程碑、连续里程碑

## 安装与使用
1. 将本目录（`lifebuddy-rpg/`）整体打包为 ZIP，名称与 `SKILL.md` 中 `name: lifebuddy-rpg` 保持一致。
2. 在 AstronClaw / SkillHub 上传该 ZIP 即可启用。
3. 对话中自然表达需求即可，例如：
   - "早安，今天怎么安排？"
   - "帮我把'准备答辩'拆成任务副本"
   - "我想养成早睡习惯"
   - "今天好累，想聊聊"
   - "帮我写条朋友圈文案"
   - "我最近成长得怎么样？"

## 质量自检（自动评测适配）
本 Skill 内置隔离式自检，**绝不触碰真实用户档案**：
```bash
python scripts/lifebuddy.py self-test
```
- 退出码 `0` = 全链路通过（init/画像/副本/习惯/树洞/可视化/边界/升级均不崩溃且数值自洽）。
- 退出码 `1` = 存在失败项，会列出具体原因。
- 自检在临时目录运行，结束后自动清理，可安全重复执行，便于 AstronClaw 质量评测与 CI 验证。

## 技术要点
- **零外部依赖**：状态脚本仅用 Python 标准库（`requirements.txt` 注明无需安装任何包）。
- **本地优先**：所有记忆写入 `{baseDir}/data/profile.json`，不联网、不外传。
- **优雅降级**：无状态文件自动初始化；图像失败仅跳过多模态；异常输入不崩溃。
- **可视化成长**：`get`/成长档案馆输出 ASCII 五维条形图 + 累计经验轨迹（任何环境可读），并可选附 Mermaid 图（不支持时仅忽略该块）。
- **结构清晰**：`SKILL.md`（主指令）+ `references/`（规则/ schema/ 评分对照/ 提示词）+ `scripts/`（状态管理，含 self-test）+ `examples/`（完整样例）。

## 安全合规与红线
仅本地读写技能目录内 `data/`；不访问用户其他文件、不发起网络请求、不索取任何凭证；不删除技能外文件。用户动态文本不生成可点击外部链接。详细红线与证据见 `references/scoring-map.md` 与 `SKILL.md` 第七节。
